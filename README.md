# Milk Quality AI Web Application (Flask)

This project wraps the existing milk-grade classifier in a web application built with Flask, HTML, CSS and a little Jinja templating.

## 1. Project files

```text
milk_quality_webapp/
├── app.py
├── milk_logic.py
├── train_model.py
├── requirements.txt
├── Milk_Grading__1_.csv   # add your actual dataset here
├── milk_model.joblib      # generated by training; do not edit manually
├── templates/
│   └── index.html
└── static/
    └── style.css
```

## 2. Open in VS Code

1. Extract the project ZIP.
2. Open the `milk_quality_webapp` folder in VS Code.
3. Copy your real dataset into the project root and name it `Milk_Grading__1_.csv`.
4. Confirm the dataset has `pH`, `Temprature` (or `Temperature`), `Taste`, `Odor`, `Fat`, `Turbidity`, `Colour`, and `Grade`.

## 3. Create a virtual environment (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use Command Prompt and run:

```bat
.venv\Scripts\activate.bat
```

## 4. Train the model

```powershell
python train_model.py
```

This creates `milk_model.joblib`. Training uses the CSV you supply; the application deliberately does not silently invent synthetic training data if the dataset is missing.

## 5. Start the website

```powershell
python app.py
```

Open `http://127.0.0.1:5000` in your browser. Keep the terminal open while using the site.

## Important scientific limitation

The supplied prototype maps each grade to a fixed TPC proxy and uses fixed shelf-life rules. Those outputs are not true learned TPC predictions or validated shelf-life predictions. This web app labels them as estimates. To claim measured TPC prediction, train and evaluate a regression model using actual paired laboratory TPC values. To estimate shelf life scientifically, collect and validate storage-time/temperature data. A model's grade confidence is not a probability of food being safe. Do not use this prototype as the sole basis for consuming or discarding food.

## Deployment beyond your PC

For a public server, use a production WSGI server, configure a real secret key, disable Flask debug mode, and follow the hosting provider's deployment instructions. `app.run(debug=True)` is only for local development.
